# 콘텐츠 작업 보조

헤르메스 에이전트가 만든 초안(`.txt`)을 업로드하면 발행에 필요한 텍스트를 한 화면에서 정리해주는
Streamlit 웹앱입니다. 한 링크 안에서 두 도구를 사이드바 메뉴로 전환합니다.

## 도구 1 — 블로그 작업 보조

- **제목**: 후보 중 라디오 버튼으로 선택 → 미리보기 + 복사
- **본문**: 블로그용 줄바꿈 정리(마침표·쉼표 기준, 숫자 속 쉼표는 보존), 한 줄 길이 조절,
  소제목 자동 표시(`@@소제목 강조`)
- **태그**: 10개 정리 → 전체 복사
- **이미지 텍스트 패키지**: 썸네일 문구 / 카드 텍스트 / 격자 표를 Canva 참고용으로 표시

## 도구 2 — 인스타 캐러셀 작업 보조

- **카드 미리보기**: 1080×1350(4:5) 비율로 카드에 텍스트를 얹어 가로 스크롤 미리보기
- **카드별 텍스트**: 카드마다 복사 → Canva 작업용
- **캡션 초안**: 카드 내용으로 인스타 캡션을 조립(편집 가능) + 해시태그 제안

## 구성

| 파일 | 역할 |
|------|------|
| `app.py` | 라우터(멀티페이지 진입점) |
| `blog_page.py` | 블로그 작업 보조 페이지 |
| `parser.py` | 블로그 초안 파싱 + 본문 포매팅 |
| `carousel_page.py` | 인스타 캐러셀 작업 보조 페이지 |
| `carousel_parser.py` | 캐러셀 초안 파싱 + 캡션 생성 + 미리보기 HTML |
| `requirements.txt` | 의존성 |

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 배포

Streamlit Community Cloud(<https://share.streamlit.io>)에서 이 저장소를 연결하고
메인 파일을 `app.py`로 지정하면 자동 배포됩니다.
