# 네이버 블로그 작업 보조

헤르메스 에이전트가 만든 블로그 초안(`.txt`)을 업로드하면 제목·본문·태그·이미지 텍스트를
한 화면에서 정리해 보여주고, 복사 버튼으로 네이버 블로그에 바로 붙여넣을 수 있는 Streamlit 웹앱입니다.

## 기능

- **제목**: 후보 중 라디오 버튼으로 선택 → 미리보기 + 복사
- **본문**: 블로그용 줄바꿈 정리(마침표·쉼표 기준, 숫자 속 쉼표는 보존), 한 줄 길이 조절,
  소제목 자동 표시(`@@소제목 강조`)
- **태그**: 10개 정리 → 전체 복사
- **이미지 텍스트 패키지**: 썸네일 문구 / 카드 텍스트 / 격자 표를 Canva 참고용으로 표시

## 구성

| 파일 | 역할 |
|------|------|
| `app.py` | Streamlit UI |
| `parser.py` | 초안 txt 파싱 + 블로그용 본문 포매팅 |
| `requirements.txt` | 의존성 |

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 배포

Streamlit Community Cloud(<https://share.streamlit.io>)에서 이 저장소를 연결하고
메인 파일을 `app.py`로 지정하면 자동 배포됩니다.
